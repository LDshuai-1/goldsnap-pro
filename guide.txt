═══════════════════════════════════════════════
  方案一 XAUUSD M15 最佳参数配置
═══════════════════════════════════════════════

1. SuperTrend
   ┌─────────────────────────────────────┐
   │ ATR周期: 10                          │
   │ ATR倍数: 2.5                         │
   │                                      │
   │ ★ 2.5是黄金M15甜点                    │
   │   1.5=太敏感 假信号多                  │
   │   3.0=滞后 趋势跑一半才确认             │
   │   2.5=平衡灵敏度和过滤噪音              │
   │                                      │
   │ 用法: 绿线出现=做多, 红线出现=做空      │
   │       变色瞬间=趋势翻转信号             │
   └─────────────────────────────────────┘

2. Heikin Ashi
   ┌─────────────────────────────────────┐
   │ 无参数 (纯算法计算)                    │
   │                                      │
   │ 用法:                                 │
   │   连续3根绿柱=上升趋势确立              │
   │   连续3根红柱=下降趋势确立              │
   │   无上下影线=强趋势 (加仓信号)          │
   │   小实体长影线=趋势衰竭 (减仓/平仓)      │
   └─────────────────────────────────────┘

3. Force Index
   ┌─────────────────────────────────────┐
   │ 平滑周期: 8                           │
   │ 平滑方式: EMA                         │
   │                                      │
   │ ★ 8比经典13更适合M15                   │
   │   13=日线经典设置, M15太慢              │
   │   5=太快 噪音多                        │
   │   8=两小时平滑 刚好跟上M15节奏           │
   │                                      │
   │ 用法:                                 │
   │   >0 + 上升=买方力量增强 (多)           │
   │   <0 + 下降=卖方力量增强 (空)           │
   │   零轴金叉/死叉=趋势确认                │
   └─────────────────────────────────────┘


═══════════════════════════════════════════════
  入场/出场规则 (四确认法)
═══════════════════════════════════════════════

做多条件 (4个全满足):
  ✅ SuperTrend绿线
  ✅ Heikin Ashi连续3阳 + 柱体有实体
  ✅ Force Index > 0 且在上升
  ✅ Aroon Up > 70 且 Aroon Down < 30

做空条件 (4个全满足):
  ✅ SuperTrend红线
  ✅ Heikin Ashi连续3阴 + 柱体有实体
  ✅ Force Index < 0 且在下降
  ✅ Aroon Up < 30 且 Aroon Down > 70

出场信号 (任一个触发):
  🚪 SuperTrend变色 (最强信号)
  🚪 Heikin Ashi出现反向长影线
  🚪 Force Index零轴反向穿越
  🚪 Aroon Up/Down交叉 (趋势衰弱)


═══════════════════════════════════════════════
  实盘经验
═══════════════════════════════════════════════

1. SuperTrend变色是最可靠的出场信号
2. 4确认全部满足才入场, 宁可等不要追
3. Heikin Ashi无影线=抓住了一段强趋势, 不要提前跑
4. Force Index如果在零轴附近震荡 → 横盘 → 不入场
5. Aroon双线都在50以上/以下 → 强趋势, 加仓
6. Aroon双线都在50附近 → 无方向, 等待
